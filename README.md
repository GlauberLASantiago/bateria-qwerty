# 🥁 Bateria QWERTY GL — Professional Performance Console

Uma estação de bateria e percussão baseada em navegador, projetada para performance em tempo real.

## ✨ Características Principais

- **Mecanismo de Som Híbrido (Pro Edition):**
  - **Kick & Snares:** Alimentados pela biblioteca *JCLive* para garantir o soco (punch) necessário no cerne da batida.
  - **Pratos e Percussões:** Alimentados pela biblioteca *FluidR3 GM* para timbres cristalinos e decaimentos realistas.
- **Engine de Rufo Inteligente (Chaos Engine):**
  - **Acionamento Automático:** Mantenha a tecla pressionada para disparar rufos/rolos.
  - **Velocidade Amortecida:** Notas de rufo são tocadas a 65% da força inicial para criar "ghost notes" realistas.
  - **Cadência Adaptativa:** Intervalos inteligentes baseados na física do instrumento (ex: Toms e Congas mais lentos, Pratos mais rápidos).
  - **Atraso Configurável:** Ajuste o tempo de espera para o início do rufo via slider.
- **Interface Premium (Glassmorphism):**
  - Design moderno com transparências, desfoque de fundo e animações dinâmicas.
  - **Feedback Visual:** Teclas brilham com cores vibrantes ao serem acionadas.
  - **Totalmente Responsivo:** Otimizado para Desktop, Tablets e Smartphones.
- **Efeitos em Tempo Real:**
  - Reverb com múltiplos presets (Small Room, Great Hall, Church, etc.).
  - Controle de volume mestre.

## ⌨️ Mapeamento de Teclas

O console oferece 33 sons mapeados em 4 fileiras:

- **Fileira Numérica:** Percussões e Efeitos (Vibraslap, Timbales, Triângulo, Agogô)
- **Fileira Q-P:** Pratos e Hi-Hats (Splash, Crash, Ride, Open/Closed HH)
- **Fileira A-L:** Caixa e Tons Agudos (Snares, High Toms, Sidestick)
- **Fileira Z-M:** Bumbos e Tons Graves (Kicks, Low Toms, Floor Toms)

*Dica: Use as teclas `-`, `0` e `=` para alternar a intensidade (Velocity) entre Piano, Mezzo e Forte.*

## 🛠️ Tecnologias Utilizadas

- **HTML5 & CSS3** (Custom Properties, Flexbox, Grid, Glassmorphism)
- **JavaScript (Vanilla)**
- **WebAudioFont Player:** Biblioteca para síntese de som de alta qualidade.
- **Google Fonts:** Fontes *Outfit* e *JetBrains Mono*.

## 🚀 Como Usar

1. Clone o repositório ou baixe o arquivo `bateria.html`.
2. Abra o arquivo `bateria.html` em qualquer navegador moderno.
3. Clique em qualquer lugar da tela para ativar o sistema de áudio.
4. Comece a tocar usando o teclado do seu computador!
